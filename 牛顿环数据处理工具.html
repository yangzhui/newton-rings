数据校验规则

为避免无效数值进入计算，录入数据会逐行检查：

  • 空行 / 注释行：自动跳过，不计入。
  • 非数字（如 abc、8.6.2）：该行报错并忽略。
  • 级数：必须为非负整数（允许 30.0，自动取整）；出现小数会提示。
  • 直径：必须为正数且有限；0、负数按无效处理。
  • 重复级数：同一级数只保留第一次出现，并给出提示。
  • 数据点数：线性拟合至少需 3 对；逐差法至少需 4 对（2 组配对）。

④ 计算原理（与文献一致）

暗环满足光程差条件 δ = r²/R + λ/2 = (2K+1)λ/2，故暗环半径 r_K² = K R λ。环心位置不易确定，用直径 D 替换半径 r 得

D_K² = 4 R λ · K

即 D_K² 与环序数 K 成线性关系，这是逐差法与线性拟合共同的出发点。

逐差法：取等间距的两组环 m 与 s（m − s = 常数），由 D_m² − D_s² = (m − s)·4Rλ 得 R = ⟨D_m² − D_s²⟩ / [4(m−s)λ]。
Origin 线性拟合法：以 K 为自变量、D² 为因变量作线性拟合 y = A + Bx， 斜率 B = 4Rλ，故 R = B / (4λ)。

本工具严按上述两式实现：拟合采用最小二乘法，不确定度按 s_R = s_B/(4λ) 与 s_R = S/[4(m−s)λ] 传递，波长统一换算为 mm 参与运算。

⑤ 在 Origin 中复核（可选）

  1. 点击上方「导出计算数据（CSV）」，得到 K、D、D² 三列。
  2. Origin 中 File → Import → CSV，或直接复制表格粘贴进 Workbook。
  3. 选中 A(X)=K、B(Y)=D² 两列 → Plot → Scatter。
  4. Analysis → Fitting → Linear Fit → Open Dialog，勾选 Show Formula on Graph，点 OK。
  5. 在 Results Log 读取 Intercept、Slope 及其 Standard Error。
  6. 新增一列输入 col(R) = col(Slope)/(4*5.893e-4) 得到 R（mm）。

注意：Origin 的 SD 是拟合变量 Y 的标准差；报告曲率半径不确定度时， 应使用 Slope 的标准误按 s_R = SE(B)/(4λ) 传递，二者量纲不同不可混用。
